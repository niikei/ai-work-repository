# Resources

Repository外にある重要な原本や記録への管理された案内を置きます。

対象はWebページに限らず、外部文書、ファイル、チケット、データセット、メール、物理資料など
です。AIがリンク先を読めるとは仮定せず、場所、用途、owner、アクセス、確認日、必要な
人間による要約を本文へ記載します。

一時的な参照はLog、Project、Areaなどへ直接貼り、複数の文脈で継続利用する重要な原本だけを
Resourceへ昇格します。

一つのProjectまたはAreaだけが所有する外部成果物は、そのEntity配下の
`external-resource` Artifactにします。複数の文脈で共有する原本、または特定Entityへ
所有させるべきでない資料だけをLibrary Resourceにします。
