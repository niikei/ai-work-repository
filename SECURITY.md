# Security Policy

## Supported versions

Security fixes are applied to the latest release and the `main` branch.

## Reporting a vulnerability

Do not disclose a suspected vulnerability in a public Issue.

Use
[GitHub private vulnerability reporting](https://github.com/niikei/ai-work-repository/security/advisories/new)
and include:

- affected version or commit;
- reproduction steps;
- expected and actual behavior;
- potential impact;
- any suggested mitigation.

Do not include real workplace documents, credentials, access tokens, or personal information in a
report. Use synthetic examples.

An initial acknowledgement should normally arrive within seven days. Resolution timing depends on
severity and the complexity of a safe fix.
